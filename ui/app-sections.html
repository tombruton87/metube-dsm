Download folder

The package makes the last folder if it may write in the shared folder, but never makes a shared folder. MeTube runs as the package's own user, so it needs Read/Write on that shared folder (Control Panel → Shared Folder → Edit → Permissions → System internal user → metube). iPhone and iPad: a Shortcut in the Share menu

  1. Open Shortcuts → +. Tap the ⓘ (Details) and turn on Show in Share Sheet; under Share Sheet Types keep only URLs and Safari web pages.
  2. Add the action Get Contents of URL. URL: — Method: POST — Request Body: JSON, with these fields (Text): ; for url pick the variable Shortcut Input.
  3. Optional: add Show Notification “Sent to MeTube”. Name the shortcut MeTube.
  4. In YouTube, Safari or another app: Share → MeTube. Downloads start at once.

The Shortcut talks to MeTube directly, so it works only where your iPhone can reach — at home, or over a VPN.

Android

  1. Scan the share page QR code above, open it in Chrome, then ⋮ → Add to Home screen.
  2. In YouTube or another app: Share → Copy link. Tap the MeTube icon on the home screen, paste into the box and tap Download.

With HTTPS (DSM's reverse proxy, on the Site address tab), Chrome can install MeTube's own page as an app (⋮ → Install app); MeTube then appears straight in Android's Share menu.

MeTube downloads with yt-dlp. Sites change how they deliver video often, and an older yt-dlp then fails — with “Unable to extract”, “Sign in to confirm”, HTTP 403 or “Requested format is not available”. New MeTube releases come every week or two, each with a current yt-dlp: updating MeTube is how yt-dlp stays current.

Update

How updating works

Update backs up MeTube's state first (the queue and the lists — your downloaded files aren't touched), downloads the newest MeTube release, starts it, and removes only the old MeTube image. Downloads under way start again where they were. If the new one doesn't start, the version from before comes back. The package also looks for a new release twice a day and shows a badge here; DSM tells you when downloads start failing in a way that suggests yt-dlp is out of date.
